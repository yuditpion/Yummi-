# Yummi · יאמי ווינרב – אתר

אתר סטטי (HTML / CSS / JS), בלי התקנות. פותחים את `index.html` בדפדפן, או מעלים את כל התיקייה לכל אחסון (Netlify, Vercel, cPanel וכו').

## מבנה
- `index.html` – כל התוכן (עברית, RTL)
- `assets/css/style.css` – עיצוב. דסקטופ נמדד 1:1 מעיצובי ה-PNG, מובייל מעיצובי המובייל
- `assets/js/main.js` – אנימציות, גלילה חלקה (Lenis), תפריט נייד, טופס
- `assets/fonts/` – Plinko (כותרות Black, טקסט Light/Regular) + Allison (הכתב האנגלי)
- `assets/img/` – תמונות שנחתכו מהעיצוב, נוקו מטקסט והוגדלו לחדות

## מה צריך להשלים
1. **מייל, וואטסאפ וטלפון** – בפוטר (`index.html`, חפשו `hello@yummi.co.il` ו-`972500000000`).
2. **הטופס** – כרגע הוא פותח מייל מוכן ל-`CONTACT_EMAIL` שבראש `assets/js/main.js`.
   לשליחה אמיתית ברקע: פותחים טופס ב-Formspree (או Make/Zapier) ומדביקים את הכתובת ב-`FORM_ENDPOINT`.
3. **קישורי מדיניות פרטיות / תנאי שימוש / נגישות** – כרגע `#`.
